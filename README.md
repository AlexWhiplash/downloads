# Загрузки

Здесь лежат готовые к запуску сборки моих проектов. Исходного кода тут нет —
он в отдельных репозиториях, часть из них закрыта.

Смысл этого места простое: **постоянная открытая ссылка на скачивание**,
не зависящая от того, открыт ли код конкретного проекта.

## Как скачать

Откройте [Releases](../../releases) и возьмите нужный файл из самого верхнего
выпуска своего проекта.

Метки выпусков начинаются с имени проекта, чтобы соседние не путались между
собой: например `orpheus-omarchy-2026.10.18.1`.

## Про предупреждение Android

При установке файла, скачанного напрямую, Android спросит разрешение ставить
приложения из этого источника. Это обычный вопрос для любого файла не из
магазина, а не признак того, что с ним что-то не так.

Отладочные сборки помечены словом «отладочная» и ставятся **рядом** с обычным
приложением, не затирая его данные.

## Про предупреждение Windows

При первом запуске Windows может показать «Windows защитила ваш компьютер».
Это не значит, что с файлом что-то не так: предупреждение появляется у любой
программы, которую система видит впервые и у которой нет накопленной репутации
среди миллионов скачиваний.

Нажмите «Подробнее» → «Выполнить в любом случае».

Убрать предупреждение совсем можно, скопировав файл на машину флешкой или
по локальной сети: тогда Windows не помечает его как скачанный из интернета
и не проверяет.
